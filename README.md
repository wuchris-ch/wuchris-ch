# Building tools that make complex work clearer.

I build full-stack applications, developer tools and data platforms, including AI agents for code review and software workflows. My focus is reliable systems, clear interfaces and reproducible results.

## Selected work

### [Agent Evaluation Platform](https://github.com/wuchris-ch/agent-eval-platform)
Compare agent behavior with independent checks, repeatable trials and inspectable evidence. Includes an experiment workbench, isolated execution and trace-based failure analysis.

**Python · Kubernetes · OpenTelemetry · React**  
[Evidence explorer](https://wuchris-ch.github.io/agent-eval-platform/) · [Architecture](https://wuchris-ch.github.io/agent-eval-platform/architecture.html)

### [PR Review Agent](https://github.com/wuchris-ch/pr-review-agent-flue)
Review code changes for security and correctness. Combines deterministic checks with model review, validates findings against exact source anchors and returns structured verdicts under bounded execution budgets.

**TypeScript · Flue · Vitest · GitHub APIs**

### [Global Macro Research Workbench](https://github.com/wuchris-ch/global-liquidity-credit-tracker)
Explore economic releases, liquidity and credit data through interactive dashboards. Research recipes preserve source snapshots and export replay manifests for independently reproducible calculations.

**Next.js · TypeScript · Python · pandas**  
[Open application](https://global-liquidity-credit-tracker.vercel.app/) · [Release laboratory](https://global-liquidity-credit-tracker.vercel.app/research/lab)

### [Research Reproducibility Workbench](https://github.com/wuchris-ch/science-research-reproducibility-platform)
Inspect published analyses, review execution plans and compare regenerated results. Links methods, datasets and runtime versions in portable provenance bundles.

**React · FastAPI · Python · R · Docker**

## Engineering focus

- **Reliable systems:** bounded execution, durable state and explicit failure handling.
- **Verifiable behavior:** independent checks, regression tests and source-linked results.
- **Usable tools:** clear interfaces for exploring data, inspecting runs and understanding outcomes.
